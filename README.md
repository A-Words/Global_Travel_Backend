# Global Travel Backend

Node.js and TypeScript backend for the Global Travel project.

## Scripts

```bash
npm run dev
npm run build
npm start
```

## Project Structure

- `src/app.ts`: Express application entry point.
- `src/routes`: API route definitions.
- `src/models`: Database access models.
- `src/config`: Database and logger configuration.
- `src/services`: External service clients.
